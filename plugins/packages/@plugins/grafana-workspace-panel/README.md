# Grafana Workspace Panel

Version: %VERSION%
Last Updated: %TODAY%

An example Grafana panel plugin built with the ejected monorepo structure. Use it as the starting point for new visualizations.

## Features

- Reads query results from `data.series` (`PanelProps`)
- Theme-aware rendering via `useTheme2`
- Configurable panel options via the options builder (`module.ts`)
- Shared utilities from `@shared/core`
